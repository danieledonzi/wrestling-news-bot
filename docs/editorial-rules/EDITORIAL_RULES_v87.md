# EDITORIAL RULES v87

## Report

Restano valide le regole v86.9: i true-results report hanno priorità, source recovery e dedupe stretto.

## Opinion/interview sotto 55

Gli articoli di commento, podcast, opinioni o interviste leggere sotto 55 non sono pubblicabili come tier3 se non contengono un fatto concreto nuovo.

Esempi da bloccare sotto 55:

- "reveals why"
- "doesn't think"
- "believes"
- "comments on"
- "looks back"
- "failed as executive"

## Link nel body

Il bot non deve linkare automaticamente nomi di wrestler o parole nel testo. I link autorizzati sono solo quelli necessari per embed/social/video o URL espliciti.
