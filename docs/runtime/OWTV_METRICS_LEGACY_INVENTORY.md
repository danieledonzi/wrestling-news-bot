## Classification rule

A numeric field remains raw runtime data or diagnostic aggregation unless it has one authoritative source, a stable counted entity, explicit identity and aggregation rules, a bounded window, and distinct zero/missing semantics. Events, API attempts, fallbacks, final results, and unique content must never be merged merely because their values happen to reconcile in one run.
