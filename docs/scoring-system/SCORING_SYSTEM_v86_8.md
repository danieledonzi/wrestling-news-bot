# Scoring System v86.8

## Nuovo cap executive/opinion

Default:

```text
executive interview/opinion max 72
```

Esempi cappati:

- “Cody Rhodes says he failed as a wrestling executive but wants to try again”
- interviste/podcast su ruoli manageriali futuri senza notizia concreta

Non vengono cappati:

- media rights
- revenue/earnings
- contract extension
- acquisition/merger
- lawsuit/settlement
- roster cuts/pay cuts
- new executive deal

## Report

I `TRUE_RESULTS_REPORT` mantengono protezione hard e priorità pending.
