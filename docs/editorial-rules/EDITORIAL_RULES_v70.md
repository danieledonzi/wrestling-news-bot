# Editorial Rules v70

La v70 mantiene le regole v68/v69 e aggiunge tre blocchi generali.

## 1. Preview

Una preview esplicita resta sempre `PREVIEW`, anche se contiene nomi forti, match annunciati o termini da storyline.

Esempi da trattare come preview:

- `SmackDown Preview`
- `Confirmed Matches`
- `Start Time`
- `How to Watch`
- `Tonight on Raw/Dynamite/Impact`

Una preview:

- non è una post-show news;
- non riceve floor post-show;
- non può diventare follow-up autonomo;
- se scaduta, viene bloccata dal filtro freshness.

## 2. News post-show

Restano valide le regole v68:

- cambio titolo;
- vittoria importante;
- debutto;
- ritorno;
- attacco;
- infortunio;
- angle rilevante avvenuto durante una puntata.

Questi contenuti sono pubblicabili anche se esiste già il report completo dello show.

## 3. Traduzione wrestling italiana

La traduzione deve interpretare il contesto wrestling, non convertire parola per parola.

Esempi corretti:

- `connected with a spear` -> `ha colpito con una spear` oppure `ha messo a segno una spear`.
- `connected a flurry of punches` -> `ha messo a segno una raffica di pugni`.
- `the tide turned/switched` -> `l’inerzia del match è cambiata`.
- `well-connected backstage` -> `ben introdotto nel backstage` / `con agganci nel backstage`.

Esempi da evitare:

- `ha collegato una raffica`;
- `la marea è cambiata`;
- `ben collegato`;
- `collegato nel backstage`.

## 4. Immagini interne

Nei report strutturati le immagini interne fanno parte del contenuto editoriale.

Regola:

- featured image: immagine principale del post;
- immagini interne: vanno caricate su WordPress e reinserite nel corpo nei punti originali;
- non vanno eliminate solo perché il tema mostra già la featured image.
