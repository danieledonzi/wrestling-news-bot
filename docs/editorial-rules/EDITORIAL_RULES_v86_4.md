# EDITORIAL_RULES v86.4

## Report authority rule

A complete results/report article is a special editorial class. It can be skipped only if WordPress strictly confirms that the same complete report already exists.

Generic duplicate signals are not enough:

- same URL in local history;
- same title key;
- same semantic ID;
- same broad story signature;
- title seen earlier in the same run;
- generic event-key match.

These signals can be logged, but they cannot block a report before strict report confirmation.

## Post-show outcome rule

The v68/v70 rule remains active: concrete post-show news can be published even if a full report exists.

Examples:

- in-ring debut;
- return;
- attack;
- victory;
- title change;
- new champion;
- retained title;
- major angle during a show.

Old low-score skipped-history records must not hide a newly recognized post-show outcome.

## Normal-news rule

For non-report and non-rescued post-show items, the existing gates remain strict:

- URL history skip;
- semantic/title skip;
- skipped-history TTL;
- preview freshness skip;
- opinion caps;
- validation gates.
