# EDITORIAL_RULES v86.5

## Regola centrale
Il trattamento speciale dei report vale solo per report completi di risultati, non per articoli genericamente “reportati”.

## TRUE_RESULTS_REPORT
Esempi validi:

- `WWE NXT Results, Highlights and Key Moments for May 12, 2026`
- `WWE NXT Results 5/12 - ...`
- `AEW Dynamite Results for May 13, 2026`
- `WWE Raw Results, Highlights and Key Moments...`

## Non sono results report

- `WWE Raw Viewership & Ratings Report`
- `Backstage Update Emerges...`
- `Wyatt Sicks Set for First Wrestling Appearance...`
- `AEW Talent Already Pushing...`
- rumor, status update, opinion, preview, ratings/viewership.

## Deduplica report
Un vero results report può essere bloccato solo se WordPress conferma in modo stretto un report completo già pubblicato.

## Post-show news
Le news singole post-show restano nella pipeline normale: possono essere pubblicate se forti, ma non ricevono bypass da report.
