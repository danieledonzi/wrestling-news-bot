## ED-1.1 Shadow V2 measurement

V2 replaces—not accompanies—the V1 provider call beneath the same disabled-by-default Shadow flag. Historical V1
artifacts and its 48-hour baseline remain immutable. V2 uses compact request-local refs, records provider-output bytes,
and retains per-attempt structured validation families and local canonicalizations in explicitly V2 diagnostic packages.

Live comparisons must report explicit denominators for logical requests, primary validity, repairs, repair recovery,
terminal invalidity, validation and canonicalization families, token usage, canonical ledger cost, and output bytes.
Semantic review additionally measures legacy disagreement, soft `SELECT`, duplicate adjudication, update grounding,
retained-body use, and normalized class inversions (structurally zero). Static serialized-byte comparisons are proxies,
not cost-savings claims. Director decisions remain non-binding and cannot alter legacy Menzo or publication.
