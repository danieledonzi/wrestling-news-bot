# Editorial Rules v86.7

## True results reports

A complete show report is editorially different from a normal post-show news item.

Examples of true results reports:

- `WWE NXT Results, Highlights and Key Moments for May 12, 2026`
- `WWE NXT Results 5/12 - Zaria & Nikkita Lyons Face Tatum Paxley & Lizzy Rain, More`
- `AEW Dynamite Results for May 13, 2026`

Examples that are not true results reports:

- viewership or ratings reports;
- backstage updates;
- rumors;
- first appearance/debut news;
- future card announcements;
- possible return date articles.

## Pending truth rule

A report is not “already published” because it is pending. It is already published only when:

- the bot published it successfully; or
- WordPress strictly confirms a complete matching report.

## CTA/media rule

Final source CTAs such as “Leave your thoughts and feedback below” are removed. Media immediately before those CTAs must remain if it was extracted by the block engine.

## Future return speculation

Articles based on a possible return date, future advertising, or a speculative comeback route are capped unless the story contains a concrete official development.
