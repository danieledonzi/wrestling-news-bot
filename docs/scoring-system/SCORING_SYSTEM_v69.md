# Scoring System v69

La v69 non modifica lo scoring v68.

Restano attivi:

- freshness semantica `PREVIEW / RESULTS_REPORT / POST_SHOW_NEWS / OPINION / RUMOR / OTHER`;
- blocco delle sole preview scadute;
- report completi in Editoriali ID 13;
- floor per post-show news concrete;
- cap opinion/commentary;
- cap annuncio vago/futuro.

La release interviene sulla qualita' della traduzione e sul post-processing editoriale, non sulle soglie di pubblicazione.
