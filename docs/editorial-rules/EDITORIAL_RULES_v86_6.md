# Editorial Rules v86.6

## Source CTAs

Remove source engagement questions and comment prompts, including patterns such as:

- “Leave your thoughts and feedback below”
- “Share your thoughts”
- “Stay tuned”

Do not translate or rewrite those lines.

## Media before CTA

If an image, tweet, Instagram post, YouTube video or other valid embed appears immediately before a source CTA, preserve the media and remove only the CTA.

## True results reports

Complete show reports/results/recaps can bypass generic duplicate gates only if WordPress does not strictly confirm that the same complete report already exists.

## Future return speculation

Possible return-date articles are not treated as major concrete returns unless they contain a confirmed appearance or completed post-show development. They are capped by default at 72.
